# effector-vue/ssr (#effector-vue-ssr)

```ts
import {} from "effector-vue/ssr";
```

:::warning{title="Deprecated"}
Since [effector-vue 23.0.0](https://changelog.effector.dev/#effector-vue-23-0-0) the core team recommends using main module of `effector-vue` or `effector-vue/composition` instead.
:::

Provides additional API for [effector-vue](/en/api/effector-vue) that enforces library to use [Scope](/en/api/effector/Scope)

## APIs

- [useEvent(event)](/en/api/effector-vue/useEvent)
- [VueSSRPlugin](/en/api/effector-vue/VueSSRPlugin)

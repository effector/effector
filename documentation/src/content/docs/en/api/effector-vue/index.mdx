Effector bindings for Vue.

:::info{title="Requirements"}
`effector-vue` supports Vue 2 and Vue 3.3 or newer. Vue 3.0, 3.1 and 3.2 are not supported since [effector-vue 23.3.0](https://changelog.effector.dev/#effector-vue-23-3-0).
:::

Examples of the Composition API are written in TypeScript: `<script setup lang="ts">` and `model.ts`. In JavaScript, drop `lang="ts"` and the type annotations, the rest of the code stays the same.

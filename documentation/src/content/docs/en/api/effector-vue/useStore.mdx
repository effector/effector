# useStore (#useStore)

```ts
import { useStore } from "effector-vue/composition";
```

:::info{title="since"}
`useStore` introduced in [effector-vue 21.1.0](https://changelog.effector.dev/#effector-vue-21-1-0)
:::

Subscribes to a store and returns its state as a readonly ref, so the component updates when the store changes. Change the state **only through [events](/en/api/effector/createEvent)**. Designed for Vue 3.

[useUnit($store)](/en/api/effector-vue/useUnit#methods-useUnit-store) does the same and also handles events, effects and shapes of units.

## `useStore($store, options?)` (#useStore-store)

### Formulae (#useStore-store-formulae)

```ts
useStore($store: Store<State>, options?: ScopeOptions): Readonly<Ref<State>>;
```

### Arguments (#useStore-store-arguments)

1. `$store` ([`Store<State>`](/en/api/effector/Store))
2. `options?` (_Object_): `{ scope, forceScope }`, the same [scope options](/en/api/effector-vue/useUnit#methods-useUnit-options) as `useUnit` takes

:::info{title="since"}
`options` argument introduced in [effector-vue 23.3.0](https://changelog.effector.dev/#effector-vue-23-3-0)
:::

### Returns (#useStore-store-returns)

(`Readonly<Ref<State>>`): a shallow readonly ref whose `value` is the state of the store itself

:::info{title="since"}
The ref is shallow since [effector-vue 23.3.0](https://changelog.effector.dev/#effector-vue-23-3-0). Before that `value` was a deep readonly proxy over the state
:::

### Example (#useStore-store-example)

```ts
// model.ts
import { createStore, createApi } from "effector";

export const $counter = createStore(0);

export const { incremented, decremented } = createApi($counter, {
  incremented: (count) => count + 1,
  decremented: (count) => count - 1,
});
```

```vue
<!-- Counter.vue -->
<script setup lang="ts">
import { useStore, useUnit } from "effector-vue/composition";

import { $counter, incremented, decremented } from "./model";

const counter = useStore($counter);
const [onIncrement, onDecrement] = useUnit([incremented, decremented]);
</script>

<template>
  <button @click="onDecrement">-</button>
  <span>{{ counter }}</span>
  <button @click="onIncrement">+</button>
</template>
```

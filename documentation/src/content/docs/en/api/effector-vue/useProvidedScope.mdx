```ts
import { useProvidedScope } from "effector-vue/composition";
```

:::info{title="since"}
`useProvidedScope` introduced in [effector-vue 23.3.0](https://changelog.effector.dev/#effector-vue-23-3-0)
:::

Returns the [Scope](/en/api/effector/Scope) the component works in, or `null` when the application runs in global mode. Mostly needed for [`allSettled`](/en/api/effector/allSettled) and [`scopeBind`](/en/api/effector/scopeBind) calls written by hand: the other composables resolve the scope on their own.

**Designed for Vue 3 and Composition API exclusively.**

# Methods (#methods)

## `useProvidedScope(options?)` (#methods-useProvidedScope-options)

### Formulae (#methods-useProvidedScope-options-formulae)

```ts
useProvidedScope(options?: { forceScope?: boolean }): Scope | null;
useProvidedScope(options: { forceScope: true }): Scope;
```

### Arguments (#methods-useProvidedScope-options-arguments)

1. `options?` `{ forceScope?: boolean }`, `forceScope` throws instead of returning `null`

### Returns (#methods-useProvidedScope-options-returns)

`Scope | null`, and `Scope` when `forceScope: true` is passed.

### Examples (#methods-useProvidedScope-options-examples)

#### Prefetching data on the server (#methods-useProvidedScope-options-examples-prefetch)

```vue
<script setup lang="ts">
import { onServerPrefetch } from "vue";
import { allSettled } from "effector";
import { useProvidedScope, useUnit } from "effector-vue/composition";

import { loadUserFx, $user } from "./model";

const scope = useProvidedScope({ forceScope: true });
const user = useUnit($user);

onServerPrefetch(() => allSettled(loadUserFx, { scope, params: 1 }));
</script>

<template>
  <p>{{ user.name }}</p>
</template>
```

### Notes (#methods-useProvidedScope-options-notes)

The scope is resolved through the injection context, so call it in `setup` before the first `await`, or inside [`app.runWithContext`](https://vuejs.org/api/application#app-runwithcontext). See [EffectorScopePlugin](/en/api/effector-vue/EffectorScopePlugin) for the full resolution order.

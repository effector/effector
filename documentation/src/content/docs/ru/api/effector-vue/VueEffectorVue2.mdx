Плагин `effector-vue` для Vue 2.

# Методы (#methods)

## `VueEffector(Vue, options?)` (#methods-VueEffector-Vue-options)

### Аргументы (#methods-VueEffector-Vue-options-arguments)

1. `Vue` (_class Vue_): класс Vue
2. `options` (_Object_): не используется, оставлен для сигнатуры `Vue.use`

### Возвращает (#methods-VueEffector-Vue-options-returns)

(_`void`_)

### Примеры (#methods-VueEffector-Vue-options-examples)

```js
import Vue from "vue";
import { VueEffector } from "effector-vue";

Vue.use(VueEffector);
```

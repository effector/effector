Биндинги effector для Vue.

:::info{title="Требования"}
`effector-vue` работает с Vue 2 и с Vue 3.3 и новее. Vue 3.0, 3.1 и 3.2 не поддерживаются с [effector-vue 23.3.0](https://changelog.effector.dev/#effector-vue-23-3-0).
:::

Примеры Composition API написаны на TypeScript: `<script setup lang="ts">` и `model.ts`. Для JavaScript уберите `lang="ts"` и аннотации типов, остальной код не меняется.
